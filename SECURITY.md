## Reporting a Vulnerability

We take the security of our project seriously. If you find a security vulnerability, please do **not** open a public issue. Doing so exposes the flaw to everyone before a fix is ready.

Instead, please report security vulnerabilities using one of the following methods:

* **GitHub Private Vulnerability Reporting:** Go to the "Security" tab of this repository, click on "Advisories", and select "Report a vulnerability". (Highly recommended)
* **Email:** Send a detailed description of the issue to **your-email@example.com**.

### What to Include
To help us fix the issue quickly, please include:
* A description of the vulnerability and its potential impact.
* Clear steps to reproduce the issue (or a proof-of-concept script/code).
* The version of the software you are using.

### Our Response Process
* **Acknowledgment:** We will acknowledge receipt of your report within **48 hours**.
* **Fix & Timeline:** We will work on a fix as quickly as possible. We ask that you give us a reasonable amount of time to patch the issue before making any details public.
